# World Focus screenshots

Fresh 1920×1080 captures of the World Focus interface, recorded from the local Vite app on 2026-09-22 and optimized for the repository README.

| File | Viewport | Purpose |
| --- | --- | --- |
| `home-live-workspace.webp` | 1920×1080 | Hero: live Tokyo background, timer, task panel, and Lofi player |
| `atmosphere-selector.webp` | 1920×1080 | Select a live atmosphere by category |
| `session-options.webp` | 1920×1080 | Focus presets, calendar blocks, and full-screen mode |
| `session-plan.webp` | 1920×1080 | Timer and task planning |
| `insights-achievements.webp` | 1920×1080 | Achievements and consistency tracking |

The images are intentionally stored in `docs/assets/screenshots/` as WebP files so GitHub renders them directly without adding unnecessary weight to the repository. The interactive demo is available as `docs/assets/world-focus-demo.mp4` with a WebM fallback.
